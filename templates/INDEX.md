> Точка входа для агента: сначала сюда, потом читать. Слот без файла помечен
> `-`, не выдумывай пути. Создал, удалил или переименовал файл - обнови строку
> (это часть финализации, см. [AGENTS.md](AGENTS.md)).

## Структура
Дерево проекта живёт в одном месте - в README, раздел "Структура". Здесь его нет
и быть не должно: два дерева разъезжаются за месяц. Если README в проекте
отсутствует, не заводи его копию здесь: строка каталога помечается `-`, и ни одна
ссылка не указывает в несуществующий файл.

## Правила, которые здесь работают
- Файл в каталоге = существует. Файл пропал - убери строку или почини ссылку.
- Нет строки для нового заметного файла = каталог врёт. Добавь строку в том же
  коммите, где создал файл.
- Не тащи сюда то, что видно из `ls` (дерево) или из `git log` (история).
- Пустой слот не держи "на будущее" - удали строку.
