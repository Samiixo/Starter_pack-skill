# STATE-LOG - журнал финалов сессий

> **Свежему агенту: читать с конца.** Последняя запись и есть актуальное
> состояние проекта.
> Формат записи - как ниже. Не переписывай старые записи, только дописывай:
> один финал сессии - одна запись.

## Формат
```
### [дата, короткая метка сессии или волны] - HEAD=`hash`
Type: fact
<что сделано: факты, хабы, решения со ссылкой на ловушки (номер), вердикты>
<открыто или отложено: что следующий агент должен знать, чтобы не наступить>
```

Поле `Type:` задаёт тип записи. В этом журнале тип один: `fact`, то есть финал
сессии. Других типов здесь не бывает; если однажды понадобится, опиши его здесь
же одной строкой, чтобы поле не стало загадкой.

### [ДД.ММ.ГГГГ] - первичная настройка - HEAD=`[hash или none]`
- Создан док-порядок: AGENTS.md (правила), INDEX.md (каталог), MAP.md
  (семантика), STATE-LOG.md (этот журнал).
- Заполнено по факту репо: [1-2 строки: что проверено, что осталось спорным].
