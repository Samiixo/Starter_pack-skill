# Ритм сессии

Пять шагов. Шаг - не ритуал, а проверка: если шаг пропущен, следующая сессия
начнёт с неверной картины и повторит работу.

## Шаг 1. Заходишь
- **Что делает:** восстанавливает картину прошлой сессии до чтения кода.
- **Читает:** хвост [docs/STATE-LOG.md](../templates/STATE-LOG.md) (с конца),
  `git status`, `git log -3`.
- **Пишет:** ничего.
- **Готово, когда:** известны последний HEAD, что было открыто и что не трогать.

## Шаг 2. Разведываешь
- **Что делает:** находит точку правки, не читая лишнего.
- **Читает:** [INDEX.md](../templates/INDEX.md) (где что), затем нужный раздел
  README, затем код.
- **Пишет:** ничего.
- **Готово, когда:** можешь назвать файлы для правки и не читал ничего лишнего.

## Шаг 3. Меняешь
- **Что делает:** вносит точечную правку в рамках задачи.
- **Читает:** код вокруг правки.
- **Пишет:** код. Документы на этом шаге не трогаются.
- **Готово, когда:** правка сделана и не задела чужие файлы. Архитектурное
  решение сначала проговаривается человеку, а не воплощается молча.

## Шаг 4. Проверяешь
- **Что делает:** убеждается, что правка работает.
- **Читает:** логи и вывод сборки, тесты.
- **Пишет:** ничего.
- **Готово, когда:** сборка и тесты прошли; для UI и рантайма - живой запуск,
  если он возможен без риска.

## Шаг 5. Финализируешь
- **Что делает:** оставляет следующей сессии верную картину.
- **Читает:** чек-лист ниже.
- **Пишет:** [STATE-LOG](../templates/STATE-LOG.md) - запись в конец;
  [INDEX](../templates/INDEX.md) - если менялся состав файлов;
  [MAP](../templates/MAP.md) - если появилась опасная зона;
  [AGENTS](../templates/AGENTS.md) - если появилось новое правило.
- **Готово, когда:** чек-лист ниже пройден полностью.

## Ловушки ритма

### Агент, который читает всё
- **Симптом:** к моменту правки контекст забит содержимым посторонних файлов;
  агент пересказывает код вместо того, чтобы его менять.
- **Правило:** сначала INDEX, потом нужный раздел README, потом код. Файл,
  которого нет в INDEX, открывается только по конкретной нужде.

### Агент, который не читает ничего
- **Симптом:** правка опирается на устаревшую картину; уже сделанное делается
  заново, отвергнутый план возвращается.
- **Правило:** шаг 1 обязателен. Пока не прочитан хвост журнала, код не трогается.

### Агент, который закончил и не записал журнал
- **Симптом:** следующая сессия начинает с того же места и повторяет работу;
  вопрос "почему это уже сделано" остаётся без ответа.
- **Правило:** запись в конец журнала - часть задачи, а не украшение. Работа без
  записи не считается законченной.

### Агент, который "улучшает" соседние документы
- **Симптом:** в правку попадают файлы, к задаче не относящиеся; смешаны
  сделанное и переделанное, ревьюить нечего.
- **Правило:** комплект запрещает трогать соседние документы вне задачи. Нашёл
  расхождение - почини ровно его, в этом же прогоне, и запиши в журнал.

## Чек-лист конца сессии
- [ ] Хвост журнала прочитан, картина прошлой сессии известна.
- [ ] Правка сделана точечно и не задела чужие файлы.
- [ ] Сборка и тесты прогнаны; для UI - живой запуск, если возможен.
- [ ] В журнал дописана запись: факты, HEAD, что открыто.
- [ ] INDEX обновлён, если менялся состав файлов.
- [ ] MAP обновлён, если появилась горячая или чужая зона.
- [ ] AGENTS обновлён, если появилось новое правило.
- [ ] Замороженные планы не тронуты без прямого запроса человека.
- [ ] Все ссылки в документах ведут в реальные файлы.
- [ ] Рабочее дерево чистое, всё закоммичено.
