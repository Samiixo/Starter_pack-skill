# STATE-LOG — журнал финалов сессий

> **Для свежего агента: читать с КОНЦА** (последняя запись — актуальное состояние).
> Формат записи — как ниже. Не переписывай старые записи; дополняй.

## Формат
```
### [дата, короткая метка сессии/волны] — HEAD=`hash`
Type: fact
<что сделано: факты, хабы, решения со ссылкой на ловушки (№…), вердикты>
<открыто / отложено: что следующий агент должен знать, чтобы не наступить>
```

### [ДД.ММ.ГГГГ] — первичная настройка — HEAD=`[hash или none]`
- Создан док-порядок: AGENTS.md (правила) + INDEX.md (каталог) + MAP.md (семантика) + STATE-LOG.md (журнал).
- Заполнено по факту репо: [1–2 строки: что проверено, что осталось спорного].
