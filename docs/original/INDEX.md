# INDEX — каталог проекта (вопрос → файл)

> Точка входа для агента: **сначала сюда, потом читать**. Слот без файла — строка помечена `—`;
> не выдумывай пути. Создал/удалил файл — обнови строку (это часть финализации, см. AGENTS.md).

## Правила, которые здесь работают
- Файл в каталоге = существует. Если файл пропал — убери строку или почини ссылку (git mv, рефакторинг).
- Нет строки для нового заметного файла = каталог врёт. Добавь строку в этом же коммите, где создал файл.
- Не тащи сюда то, что видно из `ls` (дерево) или из `git log` (история).
