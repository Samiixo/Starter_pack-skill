Каждый файл отвечает на свой вопрос

Один факт живёт в одном файле и ссылается из остальных. Два места, где одно описано по-разному, разъезжаются за месяц.
AGENTS.md
Какие в проекте правила и ритм
Человек задаёт правила, агент дописывает новые. Здесь же таблица «Заморожено» - планы, которые человек отверг, чтобы новый агент не тащил их обратно.
пишет: человек + агент при новом правиле
INDEX.md
Где что лежит
Точка входа вместо чтения наугад. Без дерева и без истории: только «вопрос - файл». Нет строки для нового файла - каталог врёт.
пишет: агент при изменении состава файлов
MAP.md
Чем за это платить
Только семантика, невидимая из ls: горячие зоны, чужой код, слои без доверия. Дерево проекта здесь не дублируется.
пишет: агент при новой опасной зоне
docs/STATE-LOG.md
На чём остановились
Журнал финалов сессий. Читается с конца. Прошлые записи не переписываются никогда - иначе исчезает единственная память о том, что уже пробовали.
пишет: агент в конце каждой работы
Правило
Каждая ссылка в документе должна вести в реальное место. Документ с выдуманными путями хуже отсутствия. Именно это правило исходный комплект нарушал сам: он ссылался на README.md, которого в нём не было - поэтому в 2.0 оно проверяется командой python tools/doc_lint.py.
