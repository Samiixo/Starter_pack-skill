Ритм сессии: пять шагов

На каждом шаге известно, что читать и что писать. Без этого агент либо читает всё подряд, либо не читает ничего.
01
Заходишь
Хвост журнала и состояние гита. Узнаёшь, что уже сделано, до того как что-то менять
читает: STATE-LOG, git
02
Разведываешь
Каталог говорит, где что. Потом нужный раздел README. Потом код. Не читать наугад
читает: INDEX, README
03
Меняешь
Точечно, в рамках задачи. Архитектурные решения - сначала слово человеку
пишет: код
04
Проверяешь
Сборка и тесты как минимум. Для UI и рантайма - живой запуск, если без риска
пишет: ничего
05
Финализируешь
Журнал, каталог, карта, разделы README. Пропущенный шаг - и следующая сессия повторит работу
пишет: STATE-LOG, INDEX, MAP
Проверка doc_lintУровеньЧто означает провал
broken_linksFAILДокумент указывает в пустоту. Именно это нарушал исходный комплект: ссылался на README.md, которого в нём нет
required_filesFAILОдного из четырёх файлов нет. Ритм распадается: журнал без каталога не подскажет, где что лежит
placeholders_leftFAILОстались [скобки] из шаблона. Значит, первичная настройка не доведена до конца
known_typosFAILОпечатка в файле инструкций. Каждый агент, который его прочитает, скопирует её дальше
charsetFAILЭмодзи, стрелки или тире, которых нет в cp1251. На консоли Windows это мусор
one_treeFAILДерево проекта размножено по двум файлам. Через месяц они разойдутся
mixed_languageWARNАнглийское слово вклеено в русскую прозу. Проверяется по белому списку технических терминов
state_log_grows_tailWARNЖурнал молчит давно или в нём меньше двух записей. Ритм остановился
